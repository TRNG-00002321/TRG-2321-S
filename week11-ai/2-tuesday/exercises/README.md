# Week 11 Tuesday - Exercises

## AI Testing Fundamentals & Bias Detection

This directory contains exercises for Tuesday's session on AI testing, bias detection, fairness metrics, and robustness testing.

### Exercise List

| Exercise | Topic | Duration |
|----------|-------|----------|
| `exercise_bias_audit.md` | Conducting a bias audit on a dataset | 60 min |
| `exercise_counterfactual_generation.md` | Generating counterfactual test cases | 45 min |
| `exercise_robustness_evaluation.md` | Testing AI model robustness | 45 min |
| `exercise_stress_test_design.md` | Designing stress tests for AI inference | 45 min |
| `exercise_red_team_simulation.md` | Conducting ethical red team exercises | 60 min |

### Prerequisites

- Completed Monday's AI Enhanced Workflow content
- Python 3.10+ environment
- Familiarity with pandas for data manipulation
- Understanding of basic ML concepts

### Required Libraries

```bash
pip install fairlearn aif360 pandas numpy scikit-learn
```

### Learning Objectives

By completing these exercises, trainees will be able to:
- Conduct comprehensive bias audits on AI/ML datasets
- Generate and utilize counterfactual test cases
- Evaluate AI model robustness through perturbation testing
- Design and execute stress tests for AI inference endpoints
- Perform ethical red team exercises on AI systems
