# Week 11 Thursday - Exercises (Pair Programming)

## AI Testing Integration & Capstone

This directory contains pair programming exercises for Thursday's session on integrating AI testing into pipelines and the week's capstone project.

### Exercise List

| Exercise | Topic | Duration | Format |
|----------|-------|----------|--------|
| `exercise_ai_testing_pipeline.md` | Building automated AI testing pipelines | 90 min | Pair Programming |
| `exercise_comprehensive_audit.md` | Comprehensive AI system audit | 90 min | Pair Programming |
| `exercise_week11_capstone.md` | Week 11 Capstone Project | 120 min | Pair Programming |

### Pair Programming Guidelines

All Thursday exercises are designed for pair programming:

1. **Driver-Navigator Model**: One person types (driver), one person reviews and guides (navigator)
2. **Switch Roles**: Rotate driver/navigator every 20-30 minutes
3. **Communicate**: Verbalize your thought process
4. **Collaborate**: Both partners should understand every line of code/decision

### Prerequisites

- Completed Monday and Tuesday content
- Working knowledge of CI/CD pipelines (Week 10)
- Python environment with AI testing libraries
- Access to AI models for testing

### Capstone Requirements

The capstone project combines all Week 11 concepts:

### Learning Objectives

By completing these exercises, trainees will be able to:
- Build automated AI testing pipelines with fairness checks
- Conduct comprehensive AI system audits
- Integrate prompt engineering skills with AI testing methodologies
- Collaborate effectively on complex AI quality tasks
