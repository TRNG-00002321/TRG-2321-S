# Week 11 Monday - Exercises

## AI Enhanced Workflow & Prompt Engineering

This directory contains exercises for Monday's session on AI-enhanced workflows and prompt engineering fundamentals.

### Exercise List

| Exercise | Topic | Duration |
|----------|-------|----------|
| `exercise_workflow_integration.md` | Integrating AI into testing workflows | 45 min |
| `exercise_prompt_engineering_basics.md` | Crafting effective prompts for QA tasks | 45 min |
| `exercise_zero_vs_few_shot.md` | Comparing prompting approaches | 45 min |
| `exercise_cot_test_planning.md` | Chain of Thought for test planning | 45 min |
| `exercise_model_selection.md` | Evaluating AI models for QA tasks | 45 min |

### Prerequisites

- Basic understanding of AI/ML concepts
- Access to an AI assistant (Claude, ChatGPT, or local model)
- Completed Week 10 DevOps content
- Python environment (optional, for scripting exercises)

### Learning Objectives

By completing these exercises, trainees will be able to:
- Integrate AI assistants into their testing workflow
- Craft effective prompts using zero-shot, few-shot, and CoT techniques
- Evaluate and select appropriate AI models for specific QA tasks
- Document and iterate on prompt engineering approaches
