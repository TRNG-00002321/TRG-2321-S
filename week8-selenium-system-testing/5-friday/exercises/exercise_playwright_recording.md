# Exercise 3: Recording with Playwright Codegen

## Objective

Use Playwright's code generation tool to record user interactions, then refactor the generated code following best practices.

## Learning Goals

- Use `playwright codegen` for test recording
- Understand generated locator strategies
- Refactor recorded code for maintainability
- Apply Page Object pattern to generated code

## Time Estimate

30 minutes

---

## Core Tasks

### Task 1: Record a Test with Codegen (10 minutes)

Open your terminal and run:

```bash
# Start codegen with Java output
mvn exec:java -e -D exec.mainClass=com.microsoft.playwright.CLI \
    -D exec.args="codegen --target java https://the-internet.herokuapp.com"
```

**Recording Tasks:**
1. Click on "Form Authentication" link
2. Enter username "tomsmith"
3. Enter password "SuperSecretPassword!"
4. Click the Login button
5. Observe the secure page
6. Click Logout
7. Stop recording

The generated code will appear in the Playwright Inspector window.

**Save the generated code** to `src/test/java/com/training/playwright/generated/GeneratedLoginTest.java`

### Task 2: Analyze Generated Code (5 minutes)

The generated code might look like:

```java
// Generated by Playwright Codegen
import com.microsoft.playwright.*;

public class GeneratedLoginTest {
    public static void main(String[] args) {
        try (Playwright playwright = Playwright.create()) {
            Browser browser = playwright.chromium().launch(
                new BrowserType.LaunchOptions().setHeadless(false)
            );
            BrowserContext context = browser.newContext();
            Page page = context.newPage();
            
            page.navigate("https://the-internet.herokuapp.com/");
            page.getByRole(AriaRole.LINK, 
                new Page.GetByRoleOptions().setName("Form Authentication")).click();
            page.locator("#username").click();
            page.locator("#username").fill("tomsmith");
            page.locator("#password").click();
            page.locator("#password").fill("SuperSecretPassword!");
            page.getByRole(AriaRole.BUTTON, 
                new Page.GetByRoleOptions().setName("Login")).click();
            page.getByRole(AriaRole.LINK, 
                new Page.GetByRoleOptions().setName("Logout")).click();
        }
    }
}
```

**Analyze and document:**
1. What locator strategies did codegen use?
2. Are there any redundant actions (like click before fill)?
3. What's missing (assertions, error handling)?

### Task 3: Refactor to Best Practices (15 minutes)

Create `src/test/java/com/training/playwright/refactored/RefactoredLoginTest.java`:

```java
package com.training.playwright.refactored;

import com.microsoft.playwright.*;
import org.junit.jupiter.api.*;

import static com.microsoft.playwright.assertions.PlaywrightAssertions.assertThat;

/**
 * Refactored login test from Codegen recording.
 * 
 * Improvements over generated code:
 * 1. Converted to JUnit test structure
 * 2. Added proper assertions
 * 3. Removed redundant click() before fill()
 * 4. Added comments and documentation
 * 5. Used appropriate locator strategies
 */
public class RefactoredLoginTest {
    
    private static Playwright playwright;
    private static Browser browser;
    private BrowserContext context;
    private Page page;
    
    @BeforeAll
    static void launchBrowser() {
        playwright = Playwright.create();
        browser = playwright.chromium().launch(new BrowserType.LaunchOptions()
            .setHeadless(true));
    }
    
    @AfterAll
    static void closeBrowser() {
        browser.close();
        playwright.close();
    }
    
    @BeforeEach
    void createContext() {
        context = browser.newContext();
        page = context.newPage();
    }
    
    @AfterEach
    void closeContext() {
        context.close();
    }
    
    @Test
    @DisplayName("Complete login and logout flow")
    void testLoginLogoutFlow() {
        // Navigate to home page
        page.navigate("https://the-internet.herokuapp.com/");
        
        // Click login link - using accessible role
        page.getByRole(AriaRole.LINK, 
            new Page.GetByRoleOptions().setName("Form Authentication")).click();
        
        // Verify on login page
        assertThat(page).hasURL("https://the-internet.herokuapp.com/login");
        
        // Fill login form - removed redundant click()
        page.fill("#username", "tomsmith");
        page.fill("#password", "SuperSecretPassword!");
        
        // Submit login
        page.getByRole(AriaRole.BUTTON, 
            new Page.GetByRoleOptions().setName("Login")).click();
        
        // Verify successful login
        assertThat(page).hasURL(java.util.regex.Pattern.compile(".*/secure"));
        assertThat(page.locator("#flash")).containsText("You logged into a secure area!");
        
        // Logout
        page.getByRole(AriaRole.LINK, 
            new Page.GetByRoleOptions().setName("Logout")).click();
        
        // Verify logout
        assertThat(page).hasURL(java.util.regex.Pattern.compile(".*/login"));
        assertThat(page.locator("#flash")).containsText("You logged out");
    }
}
```

### Task 4: Extract to Page Object (Optional Advanced)

Create `src/test/java/com/training/playwright/pages/LoginPage.java`:

```java
package com.training.playwright.pages;

import com.microsoft.playwright.*;

/**
 * Page Object for login functionality.
 */
public class LoginPage {
    
    private final Page page;
    
    // Locators
    private static final String USERNAME = "#username";
    private static final String PASSWORD = "#password";
    private static final String LOGIN_BUTTON = "button[type='submit']";
    private static final String FLASH_MESSAGE = "#flash";
    private static final String LOGOUT_LINK = "a.button";
    
    public LoginPage(Page page) {
        this.page = page;
    }
    
    public LoginPage navigate() {
        page.navigate("https://the-internet.herokuapp.com/login");
        return this;
    }
    
    public LoginPage enterUsername(String username) {
        page.fill(USERNAME, username);
        return this;
    }
    
    public LoginPage enterPassword(String password) {
        page.fill(PASSWORD, password);
        return this;
    }
    
    public void clickLogin() {
        page.click(LOGIN_BUTTON);
    }
    
    public void login(String username, String password) {
        enterUsername(username);
        enterPassword(password);
        clickLogin();
    }
    
    public String getFlashMessage() {
        return page.locator(FLASH_MESSAGE).textContent();
    }
    
    public Locator flashMessage() {
        return page.locator(FLASH_MESSAGE);
    }
    
    public void logout() {
        page.click(LOGOUT_LINK);
    }
    
    public Page getPage() {
        return page;
    }
}
```

## Codegen Tips

```bash
# Record with specific browser
mvn exec:java -e -D exec.mainClass=com.microsoft.playwright.CLI \
    -D exec.args="codegen --browser firefox https://example.com"

# Record with device emulation
mvn exec:java -e -D exec.mainClass=com.microsoft.playwright.CLI \
    -D exec.args="codegen --device='iPhone 13' https://example.com"

# Record and save to file
mvn exec:java -e -D exec.mainClass=com.microsoft.playwright.CLI \
    -D exec.args="codegen -o test.java https://example.com"
```
