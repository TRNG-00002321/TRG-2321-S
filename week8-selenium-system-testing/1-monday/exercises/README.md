# Monday Exercises: Selenium WebDriver with Python

## Overview

These exercises provide hands-on practice with Selenium WebDriver using Python. You'll apply the concepts from the written content and demos to build real automation scripts.

**Time Estimate:** 3-4 hours total

## Prerequisites

- Python 3.8+ installed
- Completed Week 7 Selenium Java content
- Understanding of Python basics from Week 2

## Setup Instructions

```bash
# Create virtual environment
python -m venv selenium_env

# Activate (Windows)
selenium_env\Scripts\activate

# Activate (macOS/Linux)
source selenium_env/bin/activate

# Install dependencies
pip install selenium webdriver-manager pytest
```
