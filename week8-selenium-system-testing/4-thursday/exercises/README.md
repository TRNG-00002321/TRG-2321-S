## Pair Programming Protocol

### Role Rotation (Every 15-20 minutes)

**Driver (Typing):**
- Writes the actual code
- Focuses on syntax and implementation
- Asks clarifying questions

**Navigator (Guiding):**
- Reviews code as it's written
- Thinks about the bigger picture
- Suggests improvements and catches errors
- Keeps track of the overall progress

### Communication Guidelines
- Explain your thought process out loud
- Ask questions when something is unclear
- Discuss alternatives before implementing
- Celebrate small wins together

### Setup for Pairs
