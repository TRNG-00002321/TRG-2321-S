# Tuesday Exercises: System Testing & Integration Testing

## Overview

These exercises focus on conceptual understanding and analytical skills related to system testing and integration testing. You'll apply test design principles to classify, plan, and design tests at different levels.

**Exercise Mode:** Conceptual (Mode B) - Design/Analysis

**Time Estimate:** 3-4 hours total

## Exercise List

| # | Exercise | Type | Difficulty | Time |
|---|----------|------|------------|------|
| 1 | Test Level Classification | Analysis | ⭐⭐ | 30 min |
| 2 | System Test Planning | Design | ⭐⭐⭐ | 60 min |
| 3 | Integration Test Design | Design | ⭐⭐⭐ | 45 min |
| 4 | Stub & Driver Creation | Hybrid | ⭐⭐⭐ | 45 min |
| 5 | Test Pyramid Analysis | Analysis | ⭐⭐⭐ | 45 min |

## Prerequisites

- Completed Week 6 Unit Testing content
- Read `system-testing.md` and `integration-testing.md`
- Understanding of test levels and V-model

Each exercise produces documentation in Markdown format. Use the provided templates in the `templates/` folder.
